Greek Fluency Companion — V11.3 Quiz + Mastery System

Built on top of GTA/GFC V11.2 Daily Lessons + Clean Tabs.

What changed in V11.3:
- Preserved all V11.2 content, tools, Greek audio, daily lesson flow, clean 7-tab structure, Travel Mode, I’m Here Now, review states, SRS, personal phrases, backup/restore, and progress storage.
- Added a true mixed Session Quiz to replace Today’s 5 as the main daily proof check.
- Kept Today’s 5 as optional legacy practice; it is no longer the main proof-of-learning step.
- Added Unit Mastery Quiz with 80% passing score.
- Added Level Mastery Quiz with 85% passing score.
- Added quiz dashboard and recent score history.
- Added mastery badges on the Path tab for unit quiz status.
- Added automatic review routing: wrong quiz answers are marked Needs Review / SRS weak.
- Added automatic daily lesson completion when the Session Quiz is passed.
- Added quiz entry points from Today, Daily Lesson, Learn, Path, and Review.
- Quizzes reuse existing app content only: phrases, vocabulary, verbs, noun patterns, question builder, and saved personal items.
- No new unverified Greek vocabulary was generated for this build.

Design rule applied:
No useless cards were added. Every new card either starts a quiz, shows mastery proof, exposes weak areas, or helps the learner decide the next action.

Passing rules:
- Session Quiz: 70%
- Unit Mastery Quiz: 80%
- Level Mastery Quiz: 85%

Audit notes:
- JavaScript syntax check passed using extracted script with node --check.
- ZIP integrity check passed after packaging.
- Existing content remains in index.html; no app.js is included.
